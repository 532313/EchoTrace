# 完整“记忆”App 的开发任务

当前产品决策：所有常用交互在 Echo-Mate 完成，RK3576 作为后台中枢；浏览器和 Qt 是可选大屏扩展。脚踏、外接暂停开关和 HX711 称重托盘退出产品范围，屏幕暂停/继续保留。

每项任务使用单独功能分支和提交，完成状态以实际可操作功能为准。

| 编号 | 功能 | 完成后能做什么 | 状态 |
|---|---|---|---|
| ET-001 | 删除外接外设 | 运行、配置和当前说明无外设要求；屏幕标记及历史数据仍可使用 | 源码已完成；随 App 版本部署 |
| ET-002 | App 首页与项目 | 新建、选择、语音命名项目；默认项目可直接开始 | 待开发 |
| ET-003 | 完整录制页 | 看到预览和时长，标记、口述、暂停和结束，返回首页仍记录 | 基础控制已有，待补齐 |
| ET-004 | 主动问记忆 | 未录制时也可语音提问，显示识别文字、回答与多条结果，支持语音播报 | 待开发 |
| ET-005 | 历史和继续上次 | 浏览会话、步骤和口述，查看上次进度，开始后续记录 | 待开发 |
| ET-006 | 小屏声画回放 | 点步骤或结果即可播放，支持暂停、拖动和连续片段 | 待开发 |
| ET-007 | 整理与导出 | 改名、补口述、删除、画面对照，导出到 SD 卡 | 待开发 |
| ET-008 | 常用部署 | 固定启动与双板连接，记录安装版本和回退产物 | 部分脚本已有，待完成 |

`0.2.0` 的交付流程：打开记忆 → 新建项目 → 录制并口述 → 结束 → 查看历史 → 提问 → 点开证据播放 → 继续上次工作。每项交付附入口、操作步骤和可见结果。编译和必要检查随功能完成，不把长期压力实验作为缺失功能的前置工作。
