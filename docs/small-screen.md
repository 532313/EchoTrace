# 小屏“记忆”App 使用说明

适用版本：`0.2.0.dev2`。入口是 Echo-Mate 首页底部抽屉，向下滚动，点“记忆”。顶部显示录制和连接状态，下面是“记录 / 项目 / 历史 / 提问”四个页签。内容超过屏幕时向上滑动。

## 第一次使用

1. 点“项目”→“新建项目”。可直接保存默认名称，也可点“语音”，说完点“结束”，确认识别文字，再点“保存”。键盘可输入字母和数字。
2. 回到“记录”，点“开始记忆”。看到“记录中”、预览和递增时长，即开始保存声画。没有项目也能直接开始，后台创建默认项目。
3. 工作时正常口述；需要保留一个操作节点时点“记这一步”。“暂停/继续”控制新增记录。返回原首页仍继续录制。
4. 点“结束记忆”，等待状态变成“已停止”。后台异步完成语音转写和画面描述，稍后到“历史”查看。
5. 点“提问”→“语音提问”，说完点“结束说话”；也可以点“输入问题”。识别文字、回答和最多五条候选证据会显示在下方，点候选即可打开原始步骤。

只录制和标记不需要后台在线；项目管理、识别、查询和历史回看需要与鲁班猫连接。首次启动没有任何项目时仍可离线开始默认记录。语音输入最长约 12 秒，未点结束会自动结束；录制期间直接口述，不另外打开独立录音。

## 各页能做什么

| 页面 | 操作 | 可见结果 |
|---|---|---|
| 记录 | 开始、标记、暂停/继续、结束 | 彩色预览、会话时长、状态提示；返回首页不终止录制 |
| 项目 | 选择、新建、修改名称 | 名称保存后选中该项目；中文可用语音输入，保存前可确认 |
| 历史 | 点会话，再点步骤 | 分页列表、笔记、识别口述、自动描述、原始画面 |
| 历史 | 会话内点“进度” | 查看按步骤整理的上次进度 |
| 历史 | 会话内点“继续” | 在同一项目新建后续会话，保留上次会话 |
| 历史 | 会话内点“删除” | 二次确认后删除本次索引与源端原片；已导出的 ZIP 保留 |
| 提问 | 语音或文字问题 | 识别文字、回答、证据候选；“朗读回答”使用 Echo 扬声器 |

历史按当前项目筛选。要看其他项目，先到“项目”切换；列表每页八项，可点“上一页 / 下一页”。项目下拉框展示最近 32 个项目。

## 打开步骤后

- **回放：** 点“播放”，等待原片缓存完成。支持暂停、继续、拖动进度和跨分段播放；关闭详情会停止回放。小屏画面为 160×90、约 5fps，录制原片仍为原分辨率和帧率。它用于确认步骤，细节可在大屏查看。
- **改笔记：** 向上滑动到“改笔记”，直接编辑或点“语音”追加口述，确认后保存。识别原文和自动描述分别保留；长笔记在小屏以追加方式保存。发生版本冲突时先刷新详情，再修改。
- **对照：** 在一个步骤点“设为画面A”，返回列表打开另一步，点“对照画面”。左侧是 A，右侧是当前步骤；再次选择同一个 A 会清除选择。
- **导出：** 先结束录制，在步骤内点“导出 SD”。后台获取证据并生成 ZIP，屏幕显示进度和完成路径。文件位于 Echo 数据目录下的 `exports/`；当前实板为 `/mnt/sdcard/echotrace/exports/`。这是当前步骤的证据包，包含说明、清单和相关原始分段；单包上限 128MiB，不是全库备份。

需要细看时，原视频 MP4 与音频 WAV 是分开保存的，工作台按来源时间联合播放。原件没有缓存时先显示文字，画面会在传输完成后刷新。损坏、删除或未记录的媒体会显示不可用，系统不会补造历史。

## 使用中的提示

| 提示或情况 | 处理 |
|---|---|
| 离线 | 保持录制；恢复 Echo 到 RK 的连接后，事件与索引继续补齐 |
| 设备使用中 | 结束 EchoTrace 录制或回放后，再进入原聊天或 AI 相机；原应用占用声画设备时也要先退出 |
| 正在处理 | 让当前语音、回放准备或导出先完成；屏幕标记和原件采集不等待模型 |
| 模型不可用 / 没有识别到语音 | 检查 RK 模型配置和连接；可继续录制、标记或使用文字查询 |
| 证据不足 | 查看候选及原始记录；系统只能说明最后记录到的状态 |
| SD 空间不足 | 有序结束当前片段并提示；先导出需要的记录，再从会话内确认删除 |

原 Echo-Mate 聊天继续使用其原服务配置，EchoTrace 的本地模型不会自动替换原聊天服务。声画精度、检索率和长时间稳定性指标仍需后续真实自用评估。
