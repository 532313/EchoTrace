# 评测与验收

功能测试、模拟负载和真实操作质量评测分别报告。`demo` 和 `--simulated` 的任何问题、视频或向量都不能计入 Recall@5≥85%、证据不足≥90% 等最终指标。

准备至少 20 次独立操作会话，约 200 个问题，至少 50 个负例。按完整会话划分开发/测试集，先在开发集固定词法、向量阈值及事件参数。独立测试的问题不能改写成与笔记完全相同的句子以提高指标。

问题文件为 JSONL，每行例如：

```json
{"id":"real-001","split":"test","text":"为什么更换这条排线？","project_id":"实际项目ID","negative":false,"expected_anchor_ids":["人工标注证据ID"],"expected_source_time_us":123456789}
```

负例设置 `negative:true`，不填证据 ID。时间字段必须取来源设备的 boot 时钟，不能用人工开始提问的时间。

```sh
python3 scripts/evaluate.py evaluation/questions-test.jsonl --hub http://127.0.0.1:18081
```

报告分开记录检索耗时、ASR、生成、原始媒体获取和回放启动。负例“正确提示证据不足”按负例集合的拒答比例统计；找到记录但原件不可用应报告 unavailable，不伪装成正确拒答。

声画同步应使用同时可见、可听的敲击/闪光信号，每隔若干分钟重复，持续至少一小时；用原始媒体和来源时间测量 P95。约六秒短测中的时长接近不能证明同步误差≤200ms。

配对标注、原件校验与计算步骤见 [物理声画同步测量](av-sync-measurement.md)。该工具复用证据导出包，合成素材始终不能通过物理验收门槛。

异常测试至少覆盖：HX711 未就绪/断开、按键抖动、光变和遮挡、相机无帧、ALSA XRUN、推理退出、USB 重连、重复事件、启动 ID 变化、容量不足、断电 `.part` 恢复、已删除/损坏媒体、机器人声音被再次录入。已具备程序化测试的项目见 `tests/`；需要物理操作的项目须记录实际接线、镜像哈希、操作步骤与日志。

三组对比使用相同会话和问题：固定间隔与事件融合；词法与词法+向量；人工拖动录像与系统检索。保留每次试验的任务顺序、完成时间和成功情况。首轮不报告商业需求或安全认证结论。
